How FirmwareLens Works

FirmwareLens brings classic embedded firmware triage workflows directly into a zero-backend browser application:

  • 1. Chunked File Streaming & Web Worker Your binary is sliced in 4 MB chunks via the File API and processed inside an isolated Web Worker created from an inline Blob, keeping the UI responsive even on multi-hundred-megabyte flash dumps.
  • 2. Sliding-Window Shannon Entropy Byte frequency histograms are computed per block (256 B to 64 KB) using $H = -\sum p_i \log_2 p_i$, revealing unencrypted bootloaders, filesystem boundaries, compressed payloads, and high-entropy encrypted regions.
  • 3. Structural Header Validation Rather than matching raw 2-byte magic numbers blindly, FirmwareLens validates structural fields (such as SquashFS block logs, uImage CRC/OS/arch enums, LZMA dictionary sizes, and ELF machine headers) to suppress false positives.
  • 4. Security-Focused String Triage Extracts printable ASCII runs and classifies high-signal artifacts including /etc/shadow hashes, hardcoded credentials, private key headers, Dropbear/Telnetd/BusyBox strings, API tokens, and endpoints.

Frequently Asked Questions

What is entropy analysis in firmware reverse engineering?

Shannon entropy measures byte randomness on a scale from 0 (completely uniform, such as 0x00 or 0xFF flash padding) to 8.0 (uniformly random). Sharp rising edges typically mark transitions from bootloaders or headers into compressed filesystems (SquashFS, LZMA, gzip) or encrypted firmware blobs.

How is FirmwareLens different from binwalk?

Binwalk is a Python CLI tool that excels at recursive extraction and deep signature scanning on Linux workstations. FirmwareLens provides instant, zero-install visual triage in any browser—combining interactive entropy edge detection, validated header parsing, security string classification, and a hex inspector without uploading sensitive binaries.

Is my firmware uploaded to any server?

No. FirmwareLens is a single static HTML page with zero external network requests. All file reading, SHA-256 hashing (via WebCrypto), signature scanning, and string extraction happen strictly inside your browser's local memory.

What are the file size limits?

Because the file is streamed in chunks rather than decoded as text, FirmwareLens comfortably handles typical IoT, router, and IP camera dumps up to a few hundred megabytes (typically 256 MB–512 MB depending on available system RAM and browser tab limits).
